1. Introduction & Problem Statement

Modern university education across STEM and Data Science requires students to absorb high volumes of complex information distributed across three disjoint formats:

  1. Dense Academic Textbooks & Papers (PDF): Provide rigorous theoretical proofs and definitions, but remain completely passive, difficult to search by concept, and detached from live demonstrations.
  2. Classroom & MOOC Video Lectures (MP4/MKV): Capture high-value instructor deductions, verbal nuances, and whiteboard demonstrations, but lack instantaneous semantic searchability, visual indexing, or clickable review timestamps.
  3. Empirical Sensor & Lab Datasets (CSV/XLSX): Contain the raw physical data supporting the theory, but are rarely connected dynamically to the textbooks or lectures explaining them.

Students are forced to multitask across PDF viewers, media players, spreadsheet tools, and search engines, creating heavy cognitive load and passive, inefficient revision. HELIOS solves this trilemma through an integrated, local-first architecture.

Key Architectural Commitment: Zero Mock Data. In contrast to demo prototypes that rely on hardcoded dummy arrays, HELIOS enforces strict empty-state safety and processes only real, physical academic assets through robust, offline-capable Python and WebGL pipelines.

3. The 5 Core Modules — Group Implementation

3.1 Module 1: Smart Search (Lead: Krishi · Branch: feature/krishi-smart-search)

Smart Search ingests multi-page academic textbooks (e.g., heat12.pdf, 64 pages) and provides two search paradigms:

  • Reciprocal Rank Fusion (RRF): Fuses dense semantic embeddings with sparse BM25 lexical token rankings using the scale-invariant formula: 
    RRF(d) = Σ [ 1 / (60 + r_m(d)) ]
  • Split-Pane Academic Reader: The left pane displays ranked answers and confidence metrics; clicking citation pills (e.g., [1], [2]) immediately navigates the right pane to the exact page and highlights the referenced passage.
  • Strict Grounding: Eliminates hallucinations by deriving answers exclusively from ingested page blocks.

3.2 Module 2: Quiz Master (Lead: Vinit · Branch: feature/vinit-Quiz-master)

Quiz Master converts passive textbook reading and video transcripts into an active assessment pipeline:

  • Contextual MCQ Generation: Generates question stems with domain-accurate distractors drawn from semantic nearest neighbors in the source text.
  • Spaced Repetition Flashcards: Flip-card study cards featuring concept definitions and self-rating queues.
  • Timed Exam Campaigns: Automated progressive testing across multiple topics with instant feedback and score breakdown.

3.3 Module 3: Lecture Sync (Lead: Krish · Branch: feature/krish-lecture-sync)

Lecture Sync bridges the gap between recorded audio/video lectures and written course materials:

  • PyAV Computer Vision Extractor: Evaluates video frames via FFmpeg C-bindings, extracting whiteboard derivations, presentation slides, and architectural diagrams.
  • Verbatim Subtitle Parser: Seamlessly parses official .srt subtitle tracks with millisecond precision, falling back to local faster-whisper when subtitles are absent.
  • Jitter-Free Playback Scrolling: Eliminates the common browser stutter where 10 Hz timeupdate events fight user scrolling. By using container-scoped scrolling (container.scrollTo()) and pausing auto-sync during manual user interaction, the interface maintains a butter-smooth 60 FPS experience.

3.4 Module 4: Data Storyteller (Lead: Nidhi · Branch: feature/nidhi-data-storyteller)

Data Storyteller bridges theoretical prose and empirical data:

  • Document Narrative Arc: Analyzes page-by-page word volume, extracts empirical markers (percentages, sample sizes, sensor thresholds), and models thematic progression across chapters.
  • Tabular Lab EDA: Ingests complex experimental datasets (e.g., Dryad Urban Heat Island sensor data, 1,968 rows), calculates summary statistics, detects outliers, and renders responsive SVG Scatter, Bar, Donut, and Line charts.

3.5 Module 5: Brain Map (Lead: Vipsa · Branch: feature/vipsa-brain-map)

Brain Map organizes cross-course knowledge into an interconnected conceptual network:

  • Knowledge Triplet Extraction: Decomposes textbook chapters into (Subject, Predicate, Object) triples.
  • 3D Three.js WebGL Cosmic Visualizer: Renders concepts as interactive spherical nodes in a 3D gravitational space, with orbital camera navigation, degree centrality sizing, and edge traversal.
  • PyVis Physics Network: Generates standalone, exportable HTML physics networks for web sharing.

6. Viva Voce & Technical Defense Q&A

Q1: Why did HELIOS eliminate mock corpus fallbacks?
Defense: Mock fallbacks create a false sense of functionality that breaks in production when a user uploads real documents. HELIOS implements defensive empty states and strictly processes user-uploaded data through verified pipelines.

Q2: How was the video player scrolling glitch eliminated?
Defense: Standard Element.scrollIntoView({ behavior: 'smooth' }) triggers 10 times a second during video playback, fighting native browser scroll events and jerking the window. We replaced this with container-scoped scrolling (container.scrollTo()), bounds checking (only scroll when the item is off-screen), segment-change debouncing, and a 2.5-second user scroll freeze.

Q3: How does HELIOS ensure privacy and zero-API costs?
Defense: All embeddings, vector queries, code processing, and video frame evaluations run 100% locally on the host machine using SQLite, ChromaDB, PyAV, and faster-whisper. No sensitive student notes or research data are sent to external third-party APIs.
